= Serve LLMs on Intel Xeon CPUs
:navtitle: Welcome

In this lab you will explore *how CPU-based LLM inference works* and build a complete RAG (Retrieval-Augmented Generation) system using a model running on {intel_platform} processors via Model-as-a-Service (MaaS).

You will not deploy model infrastructure.
You will connect to a production-grade inference endpoint, understand the architecture behind it, build a RAG pipeline with real documents, and walk away knowing how enterprise CPU inference works end-to-end.

== The Scenario

Your organization wants to serve an LLM internally without GPU hardware.
The model must answer employee questions grounded in real documents -- an HR assistant backed by Retrieval-Augmented Generation.
The inference runs on {intel_platform} processors via Red Hat's MaaS platform -- $0/token, no GPU procurement, no infrastructure to manage.
