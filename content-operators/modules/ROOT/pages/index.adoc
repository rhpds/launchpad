== Verify access

. Open the *Terminal* tab.
. Run:
+
[source,bash,role=execute,subs=attributes+]
----
oc project {namespace}
oc auth can-i create deployments.apps -n {namespace}
oc get pods -n {namespace}
----
. Confirm the authorization result is `yes` and the active project is your assigned namespace.

Open the *OpenShift Console* operator tab in this lab and choose
*launchpad-public* when OpenShift asks for an identity provider. Your existing
participant session completes sign-in; there is no separate OpenShift username
or password. Launchpad grants that identity `edit` access only to
`{namespace}`.
